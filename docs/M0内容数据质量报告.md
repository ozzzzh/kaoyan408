## 4. 人工抽样核对（2026 卷）

抽取 2026 卷第 3 题独立验算：

- 中序遍历：`b, e, d, f, c, a, g`；层序遍历：`a, b, g, c, d, e, f`
- 推导：层序首元素 `a` 为根；中序左侧 `b,e,d,f,c` 为左子树、右侧 `g` 为右子树；
  层序 `b,g,c,d,e,f` → 左子树根 `b`、右子树根 `g`；继续拆分得后序 `e,f,d,c,b,g,a`
- 数据中答案 = **C**（`e,f,d,c,b,g,a`）→ **与独立推导一致** ✅
